# PUBG-Python-project
This is my project for python-course, which presents some stats about well-known battleroyal game – PUBG

It contains different info about matches of 50.000 players, like 'date', 'game_size', 'match_id', 'match_mode', 'party_size',
       'player_assists', etc

Data taken from – https://www.kaggle.com/datasets/skihikingkevin/pubg-match-deaths/data
